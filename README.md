Ассистент по документам на подходе **RAG** (Retrieval-Augmented Generation): кладёте PDF/DOCX/TXT/MD в
каталог `data/`, задаёте вопрос на естественном языке и получаете ответ, построенный **только** на
содержимом ваших документов, со ссылками на файлы-источники.

## 🌟 Что умеет

* **Реальная генерация** через любой OpenAI-compatible API: GPT/Claude/DeepSeek/Qwen/GLM и
  сторонние роутеры — провайдер, модель и ключ задаются в `.env`;
* **Автоматический обход каталога** `data/` (рекурсивно) вместо списка файлов в коде;
* **Ссылки на источники**: каждый фрагмент помнит, из какого файла он взят, и это попадает в ответ;
* **Кросс-языковой поиск** на мультиязычной модели эмбеддингов — вопрос по-русски находит ответ в
  англоязычном документе и наоборот;
* **Порог релевантности**: если подходящих фрагментов нет, ассистент отвечает «в документах нет
  информации» и **не тратит запрос к API**, вместо того чтобы выдумывать ответ;
* **Разбиение по границам абзацев и предложений** с перекрытием — слова и мысли не рвутся посередине;
* **Офлайн-режим** `--no-llm` — проверка качества поиска без обращений к API и без ключа;
* **Интерактивный режим** и **батч-режим** с сохранением результатов в JSON.

## 🛠️ Стек технологий

| Слой | Технология |
|---|---|
| Эмбеддинги | Sentence-Transformers (`paraphrase-multilingual-MiniLM-L12-v2`) |
| Векторный поиск | NumPy (скалярное произведение нормализованных векторов) |
| Генерация | OpenAI SDK (совместим с любым endpoint `/v1/chat/completions`) |
| Парсинг документов | PyPDF, python-docx |
| Конфигурация | python-dotenv |
| Тесты | pytest |

🐍 Python 3.10+ (проверено на 3.14).

## 📥 Установка

```bash
python -m venv .venv

# Windows:
.venv\Scripts\activate

# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

Затем скопируйте `.env.example` в `.env` и укажите доступ к модели:

```ini
LLM_BASE_URL=https://api.example.com/v1
LLM_API_KEY=sk-...
LLM_MODEL=deepseek-chat
```

`.env` в `.gitignore` — ключ в репозиторий не попадёт.

Это все три переменные окружения, которые нужны. Параметры чанкинга, поиска и генерации
(`chunk_size`, `top_k`, `min_similarity`, `temperature`, таймауты) находятся в полях датаклассов
`LLMConfig` и `RAGConfig` в [`src/config.py`](src/config.py) — там же написано, что каждый из них
означает.

## 🚀  Запуск

```bash
# Батч-режим: набор демонстрационных вопросов -> assistant_results.json
python main.py

# Интерактивный режим
python main.py --interactive

# Свои вопросы
python main.py -q "О чём пользовательское соглашение?" -q "Что такое бизнес-модель?"

# Другой каталог с документами
python main.py --data-dir ./my-docs

# Только поиск, без обращений к API (ключ не нужен)
python main.py --no-llm

# Показать найденные фрагменты и их оценки сходства
python main.py --show-context
```

Чуть более расширенный список флагов: `python main.py --help`.

При первом запуске скачивается модель эмбеддингов **paraphrase-multilingual-MiniLM-L12-v2**
(около 470 МБ); дальше она берётся с диска без обращений к сети.

В батч-режиме программа возвращает ненулевой код завершения, если хотя бы один ответ получить
не удалось — чтобы сбой было видно из скрипта или CI.

## 🤔 Как это работает

```
data/*.{pdf,docx,txt,md}
        |
        |  загрузка текста (pypdf / python-docx / чтение с автоопределением кодировки)
        v
   документы + имена файлов
        |
        |  разбиение по абзацам и предложениям с перекрытием
        v
     фрагменты (текст + источник)
        |
        |  Sentence-Transformers => нормализованные векторы
        v
      индекс в памяти
        |
        |  вопрос => вектор => скалярное произведение => top-K выше порога
        v
   релевантные фрагменты
        |
        |  system-промпт (правила) + user-промпт (фрагменты с источниками + вопрос)
        v
       LLM => ответ со ссылками на файлы
```

Правила в system-промпте запрещают модели выходить за пределы переданных фрагментов и требуют
указывать источник. Если ни один фрагмент не прошёл порог сходства, запрос к API не отправляется
вообще — ответ формируется локально.

## 🗂️ Структура проекта

```
rag-document-assistant/
├── data/                  # Документы для индексации
│
├── src/                   # Исходный код системы
│   ├── assistant.py         # Индексация, поиск, сборка ответа
│   ├── chunking.py          # Разбиение текста по абзацам и предложениям
│   ├── config.py            # Датаклассы настроек, доступ к модели из .env
│   ├── document_loader.py   # Чтение PDF/DOCX/TXT/MD, обход каталога
│   └── llm.py               # Клиент OpenAI-compatible API, промпты
│
├── tests/                 # Набор Unit-тестов (pytest)
│   └── ...                  # Тесты: загрузчик, чанкинг, RAG-логика
│
└── main.py                  # CLI: аргументы, вывод, батч- и интерактивный режим
```

Ассистент возвращает данные (`Answer` с текстом, ошибкой, источниками и найденными фрагментами),
а решение о том, как их показать, принимает `main.py`.

## 🧪 Тесты

```bash
pip install pytest
pytest
```

34 теста, сети и ключа API не требуют: модель эмбеддингов и LLM подменяются заглушками из
`conftest.py`. Прогон занимает доли секунды — тяжёлые зависимости в тестовый путь не попадают.

## ☑️ Проверка

Прогон выполнен на модели **claude-haiku-4-5-20251001** через сторонний OpenAI-совместимый
роутер. Пример результата — вопрос по-русски к англоязычному документу:

> **Вопрос:** Что такое бизнес-модель?
> **Ответ:** Бизнес-модель — это набор предположений, который описывает, как работает ваш бизнес и
> как он зарабатывает деньги. Она показывает, как инвестиции и деятельность (входы) создают
> ценность для клиентов (выходы)... [University Success.docx]
> **Источники:** University Success.docx

Вопрос вне тематики документов («Какая погода сегодня в Москве?») корректно отклоняется без
обращения к API.

Результаты батч-прогона сохраняются в `assistant_results.json` вместе с источниками, оценками
сходства и текстом использованных фрагментов.

## 🕵🏼‍♂️ Известные нюансы

* **Порог релевантности зависит от модели эмбеддингов.** Значение `min_similarity = 0.30`
  откалибровано под `paraphrase-multilingual-MiniLM-L12-v2` и документы из `data/`. При смене
  модели посмотрите распределение оценок через `--no-llm` и подстройте порог.
* **Индекс считается заново при каждом запуске.** Для корпуса такого размера это несколько секунд;
  на больших объёмах имеет смысл добавить кэш эмбеддингов или полноценное векторное хранилище.
* **Качество ответа ограничено качеством поиска.** Модель получает только фрагменты из `data/`:
  если ответа в документах нет, ассистент так и скажет.
